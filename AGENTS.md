## GitHub Contribution & Attribution Rules

When contributing to GitHub, **do not** identify, credit, or attribute work to Claude or any other AI or agentic tool. 

- Do not add `Generated by`, `Co-authored-by`, tool branding, signatures, or similar attribution to:
  - Commit messages
  - Pull request titles or bodies
  - Issue comments
  - Release notes
  - Other GitHub-facing content
- Present the work transparently in terms of the changes made and their rationale.
